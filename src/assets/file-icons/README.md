# File icons

Unmodified SVGs from [vscode-icons](https://github.com/vscode-icons/vscode-icons)
(`icons/` at commit `b259d35`), used by `src/components/FileTypeIcon.tsx`.

The icons are licensed under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/); branded icons
remain under their owners' licenses.

To add one, copy `file_type_<name>.svg` here (and `file_type_light_<name>.svg`
if upstream has it), then list its extensions or file names under `<name>` in
`FileTypeIcon.tsx`.
